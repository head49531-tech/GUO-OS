# GUO-OS
An operating system testing the limits of current LLMs for low-level programming in x86_64 ASM.

# NOTICE

I do not support vibe coding.

Programming relies on you actually knowing the machine, and a LLM does not.

However, i do feel it is reasonable to write projects using LLMs if you literally cannot feasibly write it.
It makes a larger repository of choices for what you can choose to pick for certain tools as a user,
and also helps with larger tech companies and monopolies.

# INFO

LLM - Deepseek 
Language - Entirely x86_64 Assembly 

Tested in VM. DO NOT run this on your machine.

# DESCRIPTION

GUO OS is a fully LLM generated operating system to test the current boundaries of generative AI in programming.
It has: 
No human code
Almost no human debugging
Human review & Issue info (user-level)

It was tested using QEMU and assembled using NASM.

Due to the constraints of this challenge (~48 hours, 10 hours of work) this will not recieve further updates except possibly commits or usage in human code.
